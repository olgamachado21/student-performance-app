StudentPerfomance

Desempenho Académico & Hábitos de Estudo

Uma aplicação só tua para analisar desempenho escolar, prever notas a partir de hábitos de estudo e detetar sinais de risco — tudo num só sítio, a correr localmente no teu computador.

  • Previsão com Machine Learning
  • 100% local e privado
  • 11 ferramentas num só lugar

A app é construída sobre um modelo de machine learning treinado num conjunto real de estudantes, que analisa dados, deteta fatores de risco, prevê notas e gera avisos automáticos. Explora por secção abaixo, ou usa o menu lateral a qualquer momento.

        Treina um modelo de Machine Learning novo e genérico sobre o teu dataset — escolhe a coluna que queres prever (o "alvo") e as colunas a usar para prever (os "recursos"). Funciona com qualquer dataset, não só dados de estudantes: regressão se o alvo for numérico, classificação se for categórico. Guardado à parte, nunca substitui os modelos principais da app.

        A tua fórmula

        Usa os nomes das colunas acima com operadores (+ − * / **), comparações (==, !=, >, >=, <, <=), "and" / "or" / "not", e as funções: soma, media, mediana, minimo, maximo, desvio, contar (sobre uma coluna inteira — dão um único resultado), absoluto, arredondar (sobre cada linha), e se(condição, valor_se_verdadeiro, valor_se_falso). Filtra as linhas com "onde" ou "where" no fim — ex.: media(G3) onde studytime >= 3.
